================================================================
  QESMAT 9: KHATA-HA-YE MOMKEN
================================================================

403 Forbidden          → IP dar allowlist nist: curl ifconfig.me + install.sh --ip-allowlist
401 Unauthorized       → TOKEN eshtebah: sudo cat db/.maintenance-token.txt
403 edit_token_required → AI_BIND=1 vali EDIT_TOKEN nist: export MAINTENANCE_EDIT_TOKEN=...
426 encryption_required → ENC_KEY nist: export MAINTENANCE_ENC_KEY=...
503 maintenance_disabled → TOKEN kamtar az 32 char: sudo ./install.sh
400 enc_stale_timestamp → saat-e client/server >5min: sudo systemctl restart systemd-timesyncd
400 enc_replay_detected → haman request dobarh: script khod nonce mikonad
429 rate_limit         → 60 req/5min: sabr kon
502 Bad Gateway        → service run nist: sudo systemctl status personal-site
