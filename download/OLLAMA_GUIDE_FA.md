## Ollama چیست؟

Ollama یه ابزاره که اجازه می‌ده مدل‌های هوش مصنوعی رو **روی کامپیوتر/VPS خودتون** اجرا کنید. نیازی به API خارجی ندارید — همه‌چیز محلی هست.

### مزایا:
- ✅ **رایگان** — هیچ هزینه‌ای نداره
- ✅ **خصوصی** — داده‌ها از VPS خارج نمی‌شن
- ✅ **بدون محدودیت** — هرچقدر خواستید درخواست بفرستید
- ✅ **آفلاین** — بعد از دانلود، اینترنت لازم نیست

### معایب:
- ❌ **RAM زیاد** — حداقل ۲ گیگ RAM لازمه (۴ گیگ توصیه می‌شه)
- ❌ **سرعت کمتر** — نسبت به API های پولی
- ❌ **مدل‌های کوچیک‌تر** — کیفیت پاسخ کمتر از GPT-4 هست

## نصب Ollama روی VPS

### قدم ۱: نصب Ollama

روی VPS این دستور رو بزنید:

```bash
# نصب Ollama
curl -fsSL https://ollama.com/install.sh | sh

# بررسی نصب
ollama --version
# باید نسخه رو نشون بده
```

### قدم ۲: اجرای Ollama

```bash
# شروع سرویس
systemctl start ollama
systemctl enable ollama

# بررسی وضعیت
systemctl status ollama
# باید active (running) باشه
```

### قدم ۳: بررسی پورت

Ollama روی پورت `۱۱۴۳۴` اجرا می‌شه:

```bash
# تست
curl http://localhost:11434/
# باید "Ollama is running" رو بگه
```

| `mistral` (۷B) | ~۴GB | ۸GB | خوب | متوسط |

### دانلود مدل:

```bash
# مدل سبک (برای VPS با RAM کم)
ollama pull llama3.2

# یا مدل با پشتیبانی فارسی بهتر
ollama pull qwen2.5

# بررسی مدل‌های دانلود شده
ollama list
```

دانلود ممکنه ۱۰-۳۰ دقیقه طول بکشه (بسته به سرعت اینترنت).

## تنظیم سایت

### قدم ۱: اطمینان از دسترسی

اول مطمئن شید Ollama از داخل Docker container قابل دسترسیه:

```bash
# روی VPS تست کنید
curl http://localhost:11434/api/tags
# باید لیست مدل‌ها رو بده
```

### قدم ۲: تنظیم از پنل ادمین

۱. وارد سایت بشید: `http://ehsanmorad.ir/user-login`
۲. با `admin` / `admin123` وارد شید
۳. به تب **Settings** برید
۴. بخش **AI Providers** رو پیدا کنید
۵. این تنظیمات رو وارد کنید:

| فیلد | مقدار |
|---|---|
| Type | `ollama` |
| Label | `Ollama (Local)` |
| Model | `llama3.2` (یا مدل دانلود شده) |
| Base URL | `http://localhost:11434` |
| API Key | (خالی بذارید) |
| Enabled | ✅ |
| Priority | `۱` |

۶. ذخیره کنید.

### قدم ۳: تست

به بخش چت سایت برید و یه پیام بفرستید. ربات باید پاسخ بده.

## آموزش شخصیت

شما می‌تونید به ربات شخصیت بدید تا بهتر پاسخ بده.

### قدم ۱: ساخت فایل شخصیت

روی VPS:

```bash
nano /root/personal-site/system-prompt.txt
```

این متن رو بذارید (به دلخواه ویرایش کنید):

```
شما یک دستیار هوشمند هستید به نام "ربات احسان".
شما روی سایت احسان مراد کار می‌کنید.

ویژگی‌های شما:
- مودب و دوستانه هستید
- به فارسی روان پاسخ می‌دهید
- اگر سوال خارج از موضوع پرسیدند، محترمانه راهنمایی کنید
- از کلمات محاوره‌ای مناسب استفاده کنید
- اگر مطمئن نیستید، صادقانه بگویید "نمی‌دانم"

موضوعاتی که می‌توانید کمک کنید:
- برنامه‌نویسی و وب
- تکنولوژی
- سوالات عمومی

هرگز:
- اطلاعات شخصی کاربران را درخواست نکنید
- به سوالات غیرمرتبط با تکنولوژی عمیق پاسخ ندهید
- ادعای دروغ نکنید
```

### قدم ۲: تنظیم در دیتابیس

```bash
cd /root/personal-site
sqlite3 db/custom.db "UPDATE AiInstruction SET content='$(cat system-prompt.txt)' WHERE name='default';"
```

## مدیریت

### دیدن لاگ‌ها:

```bash
# لاگ Ollama
journalctl -u ollama -f

# لاگ سایت
journalctl -u personal-site -f
```

### تغییر مدل:

```bash
# دانلود مدل جدید
ollama pull qwen2.5

# حذف مدل قدیمی
ollama rm llama3.2

# از پنل ادمین، مدل رو عوض کنید
```

### بهینه‌سازی RAM:

اگه VPS کم RAM داره:

```bash
# استفاده از مدل سبک‌تر
ollama pull llama3.2:1b

# تنظیم Ollama برای استفاده از RAM کمتر
echo 'OLLAMA_NUM_PARALLEL=1' >> /etc/environment
systemctl restart ollama
```

## عیب‌یابی

### مشکل: ربات پاسخ نمی‌ده

```bash
# ۱. بررسی Ollama
systemctl status ollama

# ۲. بررسی مدل
ollama list

# ۳. تست دستی
ollama run llama3.2 "سلام"
```

### مشکل: خطای اتصال

اگه سایت نمی‌تونه به Ollama وصل شه:

```bash
# بررسی پورت
ss -tlnp | grep 11434

# اگه پورت باز نیست:
systemctl restart ollama
```

### مشکل: RAM کم

```bash
# بررسی RAM
free -m

# اگه کم بود:
ollama stop  # توقف همه مدل‌ها
# یا از مدل سبک‌تر استفاده کنید
```
