## پیش‌نیازها:
- فقط Docker و Docker Compose روی VPS نصب باشه

## نصب از صفر:

```bash
# ۱. فایل zip رو روی VPS آپلود کن
scp personal-site-final.zip user@your-vps:/home/user/

# ۲. از حالت فشرده خارج کن
ssh user@your-vps
unzip personal-site-final.zip
cd personal-site-final

# ۳. اجرا کن — همه‌چیز خودکار نصب می‌شه
docker-compose up -d

# ۴. سایت روی پورت ۳۰۰۰ در دسترسه
# http://your-vps-ip:3000
```

## انتقال از VPS قدیمی به VPS جدید:

### روی VPS قدیمی:
```bash
# ۱. دیتابیس رو بک‌آپ بگیر
docker cp personal-site:/app/db/custom.db ./backup.db

# ۲. کل پوشه رو zip کن
cd /home/user
zip -r personal-site-backup.zip personal-site-final/ backup.db

# ۳. دانلود کن
scp user@old-vps:/home/user/personal-site-backup.zip ./
```

### روی VPS جدید:
```bash
# ۱. فایل zip رو آپلود کن
unzip personal-site-backup.zip
cd personal-site-final

# ۲. دیتابیس رو بازگردانی کن
docker-compose up -d
# صبر کن تا سرور بالا بیاد
docker cp ../backup.db personal-site:/app/db/custom.db
docker-compose restart

# ۳. دامنه جدیدت رو به AUTHORIZED_DOMAINS اضافه کن
# فایل src/lib/canvas-protect.ts و src/app/page.tsx رو ویرایش کن
# خط authorizedDomains رو پیدا کن و دامنه جدید رو اضافه کن

# ۴. بازسازی container
docker-compose up -d --build
```

## بک‌آپ خودکار:
- هر شب ساعت ۲ بامداد دیتابیس بک‌آپ می‌شه
- ۷ روز نگه‌داری می‌شه
- بک‌آپ‌ها در /app/backups/ ذخیره می‌شن
- برای دسترسی: `docker exec personal-site ls /app/backups/`

## بک‌آپ دستی:
```bash
# بک‌آپ
docker cp personal-site:/app/db/custom.db ./backup-$(date +%Y%m%d).db

# بازیابی
docker cp ./backup-20260826.db personal-site:/app/db/custom.db
docker-compose restart
```
